# AprendeApp 📚

## Descripción
AprendeApp es una aplicación móvil desarrollada en Android Studio con Kotlin. Su propósito es facilitar el acceso a recursos educativos mediante una interfaz sencilla e intuitiva.

## Objetivo
Proporcionar una plataforma donde los estudiantes puedan consultar, buscar, guardar y calificar recursos educativos.

## Funcionalidades
- Registro e inicio de sesión.
- Gestión de usuarios con roles de Estudiante y Docente.
- Visualización de recursos educativos.
- Búsqueda y filtrado por tipo de recurso.
- Gestión de favoritos.
- Calificación de recursos.
- Creación, edición y eliminación de recursos para Docentes.
- Conexión con una API mediante Retrofit.

## Tecnologías utilizadas
- Kotlin.
- Android Studio.
- XML.
- Retrofit.
- Gson.
- MockAPI.
- Git y GitHub.

## Arquitectura
El proyecto utiliza el patrón Modelo-Vista-Controlador (MVC) para organizar sus componentes y responsabilidades.

## Instalación
1. Clonar el repositorio.
2. Abrir el proyecto en Android Studio.
3. Esperar la sincronización de Gradle.
4. Ejecutar la aplicación en un emulador o dispositivo Android.

## API
La aplicación utiliza MockAPI para consultar y gestionar los recursos educativos.
